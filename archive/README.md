# Archive

Retired documentation and historical files, kept for reference only. Nothing in this
directory is referenced by the SSP2 web UI.

- `info_Q9_bm_ES.md`, `info_Q9_bm_AUC.md` - v1-era Benchmark help pages describing the
  retired AUC / weighted-ES tabs; superseded by `www/info_Q9_bm_METRIC.md` and
  `www/info_Q9_bm_SUMMARY.md`.
- `manual of SSP (v1, 2024) - archived.pdf` - SSP v1 (2024) user manual; retired because it
  describes features removed in SSP2.
